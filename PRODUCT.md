# Desk

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Regular users can place Telnyx calls, view their usage, request credit and buy numbers. Admins can grant Orders access to staff, who can start confirmations and follow up on their own orders. Admins can review all orders and organization analytics, approve credit, and manage the shared WhatsApp connection. Each installation serves one organization.

## Product Purpose
A shared workspace for calls, customer messages and order confirmation. All displayed balances, records and states must come from the existing application. No invented performance, customers or activity.

## Capabilities and Constraints
React/Vite frontend, Fastify server, MongoDB Atlas, Telnyx WebRTC/Call Control and Baileys. The shared WhatsApp/SMS agent handles existing orders, with customer approval before business changes. Optional English/Urdu voice callbacks use Gemini Live on Telnyx or a separately linked WhatsApp voice device. Spoken decisions require text approval. New-order creation from conversation remains unimplemented. Live order automation stays disabled unless explicitly configured. UI QA uses isolated accounts and fake providers.

## Brand Commitments
Keep the name Desk. The user supplied a Nomi AI workspace screenshot and the Figma Settings Liquid Glass UI reference. Use a charcoal sidebar, warm light content, rounded framing and restrained translucent controls. The user chose implementation directly from those references.

## Product Principles
- Preserve role boundaries and existing customer data.
- Make actions, prerequisites and outcomes visible.
- Keep unavailable functionality honest and distinguish pending provider results from completed delivery.
- Support keyboard navigation, responsive layouts, readable contrast and reduced motion.
